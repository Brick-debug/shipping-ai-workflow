# Security and data handling

This repository contains a synthetic demonstration only. Do not commit real
emails, customer names, vessel schedules, freight rates, credentials, or
employer-owned documents.

## Local secrets

Copy `.env.example` to `.env` and keep all credentials there. `.env`, Streamlit
secrets, generated spreadsheets, databases, and the `data/` directory are
ignored by Git.

## Reporting a vulnerability

Please open a private security advisory on GitHub instead of posting secrets in
a public issue.
